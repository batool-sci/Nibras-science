نبراس العلوم — ملفات الموقع الأولية

المحتويات:
- index.html: صفحات الموقع وبنية العرض.
- style.css: التصميم المتجاوب مع الهاتف والحاسوب.
- script.js: التنقل بين الصفوف والفصول والوحدات والدروس والاختبار التجريبي.

طريقة النشر على Netlify:
1. فكّي ضغط الملف ZIP على الهاتف أو الحاسوب.
2. افتحي لوحة Netlify واختر إضافة موقع/نشر يدوي (Deploy manually) إن كانت متاحة.
3. ارفعي المجلد الذي يحتوي مباشرة على index.html وstyle.css وscript.js، أو اسحبي ملفات الموقع بعد فك الضغط إلى منطقة النشر.
4. افتحي رابط الموقع الذي يعطيك إياه Netlify للتجربة.

مهم:
- هذه نسخة أولية قابلة للتطوير. بيانات الطالب لا تُرسل إلى المعلمة ولا توجد قاعدة بيانات.
- صفحة الدرس تحتوي مساحات نموذجية للشرح والنشاط واللعبة، وليست شروحًا كاملة لكل درس بعد.
- عناوين الوحدات والدروس أُدرجت اعتمادًا على فهارس كتب العلوم والحياة التي أرسلتِها. راجعي الفهرس المصوّر قبل اعتماد الموقع رسميًا، خاصة بعض عناوين الفصل الأول التي ظهر نصها المستخرج غير واضح بالكامل.
- الشعار الحالي كتابة ورمز تجريبيان، ويمكن استبدالهما بالشعار الأصلي عند تزويدنا بملفه.
